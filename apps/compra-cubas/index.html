Compra de Cubas

Necessidade das OPs abertas + consumo médio mensal das OPs concluídas, por modelo de cuba.

1. Dados do Cosmos (lidos do Supabase)

Os arquivos são gravados pelo robô; esta tela confere sozinha a cada 5 minutos se há versão nova.
2. Necessidade atual — OPs abertas
3. Consumo médio — OPs concluídas

4. Compra

Compra sugerida = necessidade + (meses × média mensal) − estoque − já em compra, arredondada para cima. Sem folga percentual. Use 0 para comprar só a necessidade.

Estoque, "Já em compra", meses de cobertura, filtros e marcações são só para simular nesta tela: nada é salvo. Ao recarregar, tudo volta ao padrão.

Clique no nome da cuba para ver as OPs e o consumo mês a mês.
Regras de leitura (consulta)

Cada linha é um texto procurado no nome do item ou na OBS da OP. A busca ignora maiúsculas, acentos e espaços ao redor do "X" ("700 X 500 X 400" = "700X500X400"), e só vale quando o texto não está colado a outros números. As variações vêm da planilha NECESSIDADE CUBAS e ficam fixas nesta tela.
